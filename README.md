# Introduction-to-Quarto
This repository provides an introduction to the use of Quarto to create reports and presentations using Python and R. The materials for this introduction are structured as follows:

* A guided introduction on what Quarto is, how to install it, and how to use it with R or Python is described on the Wiki of this repository [here](https://github.com/ZHAW-Services-Research-Data/Introduction-to-Quarto/wiki)
* The materials for the guided exercises are stored in the repository itself. 
  * You can either clone the entire repository, before starting the introductory materials, or 
  * alternatively, a link for the download of individual exercises is included in the wiki, whenever an exercise should be started.

we have tried to prepare these materials, so they can serve as self-learning materials. Should you prefer to have a guided introduction led by one of the members of ZHAW Services Researchdata, or should you have feedback for these materials, please contact us on [this email address](mailto:researchdata@zhaw.ch).
